# PROYECTO LÓGICA: Katas de Python

## Contenido del repositorio

Este repositorio incluye el fichero **`ecalderonf_DataProject_python.py`**, 
y otros programas python, que reúne el conjunto de ejercicios, 
funciones y prácticas desarrolladas en el módulo 05 Python.  
El archivo contiene implementaciones progresivas orientadas a:

- Practicar estructuras de control (condicionales, bucles).
- Definir funciones limpias y reutilizables.
- Trabajar con clases y métodos siguiendo buenas prácticas.
- Resolver ejercicios de lógica y manipulación de datos.
- Consolidar fundamentos de programación en Python.

El objetivo del fichero es servir como **documento centralizado** del trabajo realizado, permitiendo revisar, ejecutar y ampliar cada ejercicio de forma ordenada.


## Requisitos
- Python 3.10 o superior
- pip (gestor de paquetes)
- Entorno virtual recomendado (`venv`)


## Pruebas
